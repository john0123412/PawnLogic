# PawnLogic 0.3.5 Command Recovery Hardening Plan

> **Status:** Active. Implementation and release evidence will be recorded here
> before the plan is marked complete.

## Goal

Finish the command-recovery work merged after 0.3.4 so fuzzy slash-command
dispatch and interrupted-Turn recovery have one unambiguous, tested contract
before 0.3.5 is released.

## Scope

- Auto-dispatch a fuzzy slash command only when exactly one registered command
  matches. Ambiguous input must execute nothing and list its candidates.
- Keep Prompt Toolkit, readline, and direct dispatch on the same fuzzy-matching
  semantics and the live `core.commands.COMMANDS` registry.
- After a Turn interruption, Enter retries the preserved prompt once and an
  edited prompt replaces it without duplication, including edits beginning
  with `/`.
- During interrupted-input recovery, `/queue`, `/queue resume`, `/queue clear`,
  and `/abort` remain control commands instead of replacing the preserved Turn.
- Keep the English and Chinese recovery documentation and terminal hint in
  sync.
- Close the release-gate network-policy gap by rejecting `localhost` and every
  reserved `.localhost` subdomain before DNS resolution.

## Acceptance Gates

- Regression tests prove `/plg` reaches `/planguard`, while ambiguous examples
  such as `/qu` and `/md` execute no command and show all matching candidates.
- A terminal-level recovery test proves an edited `/...` prompt replaces the
  preserved queue head exactly once; queue and abort controls remain reachable.
- The recovery hint includes Enter, edit, `/queue resume`, and `/abort` paths.
- Resolver-independent tests prove the localhost namespace is classified as
  loopback and never reaches DNS.
- Relevant tests, E2E, ruff, typed-island mypy, documentation checks, release
  consistency, architecture budget, code-index freshness, and `git diff
  --check` pass.
- A release candidate later passes the Python 3.10/3.11/3.12 matrix, package
  build, fresh-install smoke, Dynamic E2E, and remote Actions before publish.

## Explicit Non-Goals

- No version bump, tag, PyPI upload, GitHub Release, or remote branch operation
  in the implementation step.
- No change to plan-guard enforcement semantics or Provider behavior.
- No cleanup or merge of stale local branches without separate authorization.
