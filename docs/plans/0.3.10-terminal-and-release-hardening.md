# 0.3.10 — Terminal Hardening and Release

> **Status:** Active. The release candidate failed owner terminal acceptance;
> Python live-output and ratatui usability repairs are under re-validation.

## Scope

Terminal stability and release-gate hardening on top of 0.3.9:

1. Live-terminal single-owner display: completed output appears exactly
   once — in the native host scrollback — while the application viewport
   shows only undelivered lines (ADR 0010 discipline, no new scheduler).
2. Release-gate hardening: the pre-commit leak scanner cannot be bypassed
   by staging the scanner itself; toolchain pinned for the Rust gates.
3. Server-command override for packaged ratatui frontends
   (`PAWNLOGIC_TUI_SERVER`).
4. Session/workspace split: `session_<id>/` scratch directories live under
   `~/.pawnlogic/sessions/`; `workspace/` keeps only user-visible outcomes.
5. Ratatui usability repair: eliminate stream/result duplication, make
   backend failures visible, restore terminal state on every exit path, and
   provide a cursor-aware Unicode composer with paste and mouse scrolling.
