# PawnLogic 0.3.1 Runtime Hardening And Release Preparation Plan

> **Status:** Active. PawnLogic `0.3.1` is an unreleased release candidate.
> Do not create a tag, publish a package, or create a GitHub Release without
> explicit authorization after all release gates pass.

## Goal

Prepare a small patch release that preserves the published 0.3.0 public
contracts while hardening stream recovery, bounded file discovery, and the
host-owned execution boundary.

## Included Work

- Tolerate up to two transient empty SSE `readline()` results from chunked
  transports, then end the stream after the third empty read to prevent busy
  loops.
- Give `find_files` a default 10-second monotonic deadline, preserve global
  mtime ordering when traversal completes, and label timed-out output as
  partial.
- Require a valid Engagement Scope before an active network probe can allow an
  authorized private target.
- Resolve every host-executed Tool Call through a complete owned ToolSpec and
  fail closed when metadata resolution or the execution-policy seam fails.
- Route public delegated tasks through the serial orchestrator so cancellation
  and shared token, tool, and cost budgets apply to the child session.
- Keep README, CHANGELOG, SECURITY, project memory, and release-plan state
  consistent with public 0.3.0 and candidate 0.3.1.

## Acceptance Gates

- `tools/check_doc_structure.py` and `tools/check_release_consistency.py`
  pass with public 0.3.0 and candidate 0.3.1.
- Focused stream, file, network policy, tool execution, delegation, and
  session tests pass before the full suite.
- Ruff, the CI typed island, code-index freshness, staged leak scans, and
  `git diff --check` pass.
- The merged `main` worktree passes the non-E2E and E2E test suites with an
  isolated `PAWNLOGIC_HOME`.

## Non-Goals And Stop Conditions

- Do not alter the existing remote `v0.3.0` tag or GitHub Release.
- Do not create `.release-ready`, tag `v0.3.1`, trigger TestPyPI/PyPI, or
  create a GitHub Release in this preparation task.
- Do not implicitly merge changes from still-open PRs beyond the commits
  already present in the selected `main` baseline.
- A single blocking filesystem operation can outlive the `find_files` deadline;
  the deadline applies at Python-level iterator boundaries and results must not
  claim otherwise.
